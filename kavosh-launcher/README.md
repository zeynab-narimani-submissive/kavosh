# Kavosh Launcher (کاوش)

یک لانچر واقعی اندروید (Kotlin + Jetpack Compose) به سبک Kvaesitso: لیست اپ‌ها،
جستجوی یونیورسال (اپ + ماشین‌حساب + وب)، برچسب‌گذاری اپ‌ها، و هاست ویجت واقعی.

این پروژه **کد منبع** است، نه یک APK آماده — چون کامپایل یک اپ اندرویدی به Android
SDK و Gradle نیاز دارد که در محیطی که این پروژه ساخته شد وجود نداشت. برای گرفتن
APK قابل‌نصب، یکی از دو مسیر زیر را طی کن.

## گزینه ۱: ساخت خودکار با GitHub Actions (بدون نیاز به نصب چیزی روی سیستم خودت)

1. یک ریپوی جدید توی گیت‌هاب بساز (خصوصی یا عمومی، فرقی نمی‌کند).
2. کل محتوای این پوشه (`kavosh-launcher/`) را داخل ریپو push کن:
   ```bash
   cd kavosh-launcher
   git init
   git add .
   git commit -m "Kavosh Launcher"
   git branch -M main
   git remote add origin <آدرس ریپوی خودت>
   git push -u origin main
   ```
3. برو به تب **Actions** در ریپو. یک workflow به اسم «Build Kavosh APK» به‌صورت
   خودکار اجرا می‌شود (فایلش از قبل توی `.github/workflows/build-apk.yml` هست).
4. وقتی اجرا تمام شد (چند دقیقه طول می‌کشد)، پایین صفحه‌ی همان اجرا بخش
   **Artifacts** را باز کن و فایل `kavosh-launcher-debug-apk` را دانلود کن.
   این یک zip حاوی `app-debug.apk` است.
5. APK را روی گوشی‌ات منتقل کن، اجازه‌ی «نصب از منابع ناشناس» را برای برنامه‌ای
   که با آن باز می‌کنی (مثلاً فایل‌منیجر) فعال کن، و نصبش کن.

این مسیر نیاز به Android Studio یا هیچ نصبی روی سیستم خودت ندارد.

## گزینه ۲: ساخت محلی با Android Studio

1. آخرین نسخه‌ی [Android Studio](https://developer.android.com/studio) را نصب کن.
2. پوشه‌ی `kavosh-launcher` را با «Open» در Android Studio باز کن؛ خودش Gradle
   Wrapper را کامل می‌کند و وابستگی‌ها را دانلود می‌کند (اینترنت لازم دارد).
3. از منوی `Build > Build Bundle(s) / APK(s) > Build APK(s)` استفاده کن.
4. APK خروجی را در `app/build/outputs/apk/debug/app-debug.apk` پیدا می‌کنی.
5. با کابل یا هر روشی به گوشی منتقل و نصبش کن.

## بعد از نصب: چطور آن را launcher پیش‌فرض کنی

بعد از نصب APK، دکمه‌ی Home گوشی را بزن؛ اندروید از تو می‌پرسد کدام لانچر را
می‌خواهی استفاده کنی — «Kavosh» را انتخاب و «Always» را بزن. برای برگرداندنش،
از تنظیمات گوشی برو به **Apps > Default apps > Home app** و لانچر قبلی‌ات را
دوباره انتخاب کن.

## وضعیت فعلی و محدودیت‌های شناخته‌شده

- کد این پروژه نوشته شده ولی **کامپایل نشده** (نبود SDK در محیط تولید). ممکن است
  در اولین بیلد به یکی‌دو تصحیح جزئی import/نسخه نیاز باشد — طبیعی برای پروژه‌ای
  به این حجم که بدون کامپایلر واقعی نوشته شده.
- ویجت‌ها: افزودن، نمایش و پایداری‌شان بین ری‌استارت‌ها پیاده‌سازی شده؛ تغییر
  اندازه یا جابه‌جایی ویجت با درگ هنوز اضافه نشده.
- پین به داک و برچسب‌گذاری از طریق منوی long-press روی هر آیکون اپ انجام می‌شود.
- جستجو از سه بخش تشکیل شده: تطبیق فازی اسم اپ‌ها (شبیه fzf)، ماشین‌حساب inline
  (فارسی/انگلیسی)، و در نهایت گزینه‌ی جستجو در وب که همیشه در پایین لیست هست.
